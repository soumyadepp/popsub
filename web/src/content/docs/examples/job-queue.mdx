## Before you start

Do the [one-time setup](/examples/#set-up-once), then let `alice` use the job topics:

```bash
popsub users grant alice 'jobs/#'
```

## The worker

<ExampleCode example="queue" file="job-worker" />

- **`subscribeShared`** joins the group `resizers`. Everyone in the group shares one stream of
  jobs, and each job goes to one member.
- It acknowledges only after the work is done. If a worker dies mid-job, the job moves to
  another member straight away.
- The one-second wait stands in for real work.

<p class="output-label">Output from w1 and w2</p>

```text
w1 took job-1
w2 took job-2
w1 finished job-1
w1 took job-3
w2 finished job-2
w2 took job-4
```

The workers take turns, and no job runs twice. Which worker gets which job can differ from
run to run.

## Things to know

- **The group remembers its place.** If every worker stops, new jobs wait on the server. The
  next worker to join picks them up.
- **A job can run twice** when a worker crashes after doing it but before acknowledging it.
  Make jobs safe to repeat.
- **No order inside a group.** Jobs are handed out in turn, but a slow worker can finish an
  earlier job after a later one.
- **One account per group.** All the workers log in as the same user.
