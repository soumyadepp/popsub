## Set up once

You need a running server, an account for the examples, and a project to keep them in.

<Steps>

1. **Start a server.** Follow step 1 of the [Quickstart](/quickstart/) and leave it running.
   The examples expect it on `ws://127.0.0.1:8080`.

2. **Create the account the examples use.** In another terminal:

    ```bash
    POPSUB_PASSWORD=password POPSUB_NEW_PASSWORD=alice-password popsub users add alice
    ```

    If you did the Quickstart, `alice` already exists, so skip this step. She starts with
    access to nothing, and each example names the one grant it needs.

    These pages write the command as `popsub`. From a download, run `./popsub` in its folder.
    With Docker, run `docker exec -it popsub popsub` instead.

3. **Make a project for the examples.** One project holds all of them. If you did the
   Quickstart, use the project you made there.

    <ProjectSetup />

</Steps>

Every example hardcodes `ws://127.0.0.1:8080` and the `alice` account, so you can read it top
to bottom. In your own code, read them from configuration instead.
